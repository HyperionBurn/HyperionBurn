## Things I've built

- [AgentWork](https://github.com/HyperionBurn/AgentWork): a prototype marketplace where AI agents hire and pay each other. It uses Arc L1 and Circle's x402 protocol for sub-cent payments, with escrow contracts and on-chain reputation. The live demo has settled 3,400+ transactions on testnet.
- [finalisma](https://github.com/HyperionBurn/finalisma): a coordination layer for multi-agent AI. One link opens a room and many agents can join. Messages are delivered in order and agents need scoped consent to act.
- [DualAgent-ERC8004](https://github.com/HyperionBurn/DualAgent-ERC8004) and [omni-ai](https://github.com/HyperionBurn/omni-ai): an on-chain trading agent, and a local agent that can run code on my machine or in Docker sandboxes.
- [CardioFlow AI](https://github.com/HyperionBurn/flowtest): estimates blood-flow pressure in coronary arteries using physics-informed neural networks. It takes under a second on a CPU where full CFD takes hours.
- [GDG Motion Arcade](https://github.com/HyperionBurn/gdg-cv-arcade): computer-vision games that run in the browser from a webcam, built for our club fair stall. They work fully offline.
- [Canvas Extracter](https://github.com/HyperionBurn/canvas-extracter-gen2): a script that archives your Canvas courses (files and module pages) before you lose access.
- [FLUXGATE](https://github.com/HyperionBurn/nexus-command-center): a command-center dashboard for school traffic and bus pickup.
- This site's portfolio, a Lamborghini Revuelto teardown that scrolls in 3D, is at [wasifwaseem.tech](https://wasifwaseem.tech).
